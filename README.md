# صدا نویس — مفت اردو آڈیو ٹرانسکرپشن (PWA)

یہ ایک static ویب ایپ ہے۔ کوئی سرور، API key یا ادائیگی نہیں۔ ٹرانسکرپشن Whisper (MIT) سے، Transformers.js (Apache-2.0) کے ذریعے، براہِ راست آپ کے براؤزر میں ہوتی ہے۔

## فائلیں
index.html · style.css · app.js (انٹرفیس، ایڈیٹر، ڈاؤن لوڈ) · worker.js (Whisper) · sw.js · manifest.webmanifest · icon.svg · PROGRESS.md

## مفت ہوسٹنگ (موبائل سے، مثال: GitHub Pages)
1. ZIP کو Files ایپ میں Extract کریں۔
2. github.com پر مفت اکاؤنٹ اور نئی public repository بنائیں۔
3. Add file → Upload files سے فائلیں اپلوڈ کریں (فولڈر کے اندر کی فائلیں، فولڈر خود نہیں)۔
4. Settings → Pages → Branch: main، فولڈر: root → Save۔ چند منٹ بعد https لنک کھلے گا۔
5. Chrome میں لنک کھول کر مینو سے "Add to Home screen" کریں۔

فائلیں file:// سے نہیں چلیں گی؛ https لازمی ہے۔ مفت ہوسٹنگ کی موجودہ شرائط اور حدود میں نے تصدیق نہیں کیں، اپلوڈ سے پہلے خود دیکھ لیں۔

## رازداری (ڈیزائن کے مطابق)
- Transformers.js لائبریری jsDelivr سے اور Whisper ماڈل Hugging Face سے ڈاؤن لوڈ ہوتا ہے (پہلی بار، پھر براؤزر کیش)۔
- ڈیزائن میں آپ کی آڈیو کسی سرور کو نہیں جاتی۔ یہ دعویٰ ابھی Network ٹیب میں تصدیق شدہ نہیں۔
- ٹرانسکرپٹ صرف اسی براؤزر کی لوکل اسٹوریج میں خودکار محفوظ ہوتا ہے؛ "متن حذف کریں" سے مٹ جاتا ہے۔

## استعمال
فائل منتخب کریں → زبان (اردو) اور ماڈل چنیں → ٹرانسکرائب کریں۔ اردو کے لیے Small عموماً بہتر مگر سست اور بھاری ہے؛ پہلے Base آزمائیں۔ نتیجہ 100 فیصد درست نہیں ہوتا، ایڈیٹر میں خود درست کریں۔

## نئے فیچرز (مرحلہ 2)
- DOCX بٹن: Word فائل بنتی ہے (کوئی لائبریری نہیں)۔
- PDF بٹن: براؤزر کا Print کھلتا ہے؛ وہاں "Save as PDF" چنیں۔
- ریکارڈ بٹن: پہلے مائیک کی اجازت دیں، ریکارڈ کریں، روکیں، پھر "ٹرانسکرائب کریں"۔ یہ لائیو ٹرانسکرپشن نہیں۔
- کام: "انگریزی ترجمہ" صرف انگریزی میں ترجمہ کرتا ہے۔
- SRT/VTT اصل ٹرانسکرپشن کے حصوں سے بنتے ہیں، آپ کی ترمیم سے نہیں۔
